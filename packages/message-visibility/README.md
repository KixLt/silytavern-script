# 楼层可见性（酒馆助手脚本）

在输入栏上方加一条开关栏，决定**哪些楼层会发给 AI**。酒馆本身只提供单条 `/hide`，
这个脚本把「楼层可见性」变成一张能扫读、能批量操作的表。

界面上与 [AI 请求监控](../ai-monitor) 共用**输入框上方的那一行**：两个脚本各挂一张卡片，
本脚本这张按内容收窄（300px，行里只有楼层号和角色），剩余宽度留给 AI 监控；只启用一个时
卡片仍只占 300px，右边留白。卡片沿用同一套视觉语言
（12px 正文、主题色派生线条与面、下划线式 Tab、同名徽标），所以这一行看起来是一个整体，
而不是两个风格不同的插件。脚本是 IIFE 注入，引 React + Radix 会让体积翻几倍，
因此全部用纯 CSS 手写。

```
┌─ ● 楼层可见   2/12 隐藏   ⏱ 定时 2   − ─┐┌─ ● AI 监控       5 条   −  × ─┐
│ [ 全部 | 用户 | AI ]                     ││ [ 实时 | 历史 5 ]              │
│ [全部可见] [全部隐藏] [清除定时]          ││ 成功 claude-sonnet-4.5 · 7.2s  │
│ 最近 [ 3 ] 轮可见            [应用]      ││ ┌─────┬─────┬─────┐           │
│ ⌄ #11 AI  “雨小了。”…            (开)    ││ │13.1k│  528│71.1%│           │
│ ⌄ #8  AI  他从柜子深处…  ⏱1 轮后可见 (开)││ 5 次 · ✓4 ✗1 …                │
└──────────────────────────────────────────┘└───────────────────────────────┘
```

| 能力 | 说明 |
| --- | --- |
| 单条开关 | 每层右侧一个开关，关掉即对 AI 隐藏（等价于酒馆的「隐藏消息」） |
| 筛选 | 顶部 `全部 / 用户 / AI` 切换列表里显示的内容 |
| 一键全部 | `全部可见` / `全部隐藏`，系统楼层不受影响 |
| 可见窗口 | `最近 N 轮可见`：更早的楼层一次性隐藏，边界保留对应的用户提问 |
| 定时规则 | 点某一层在手风琴里设置「N 轮后隐藏 / N 轮后可见」，逐轮倒数并自动执行 |
| 折叠 | 点标题栏或右侧 `−` 收起展开区，只剩一行状态（隐藏数 / 规则数 / 最后一条楼层的可见性） |

## 在酒馆中使用

酒馆助手 ‣ 脚本 ‣ 新建脚本，内容只写一行：

```js
import 'https://cdn.jsdelivr.net/gh/KixLt/silytavern-script@master/dist/message-visibility/index.js'
```

保存并启用即可，输入栏上方会出现「楼层可见」。若同时装了 `ai-monitor`，两张卡片并排：
左边是本脚本（300px 窄条），右边是 AI 监控（占剩下的宽度，也可以拖出去变成浮窗）。

## 卡片说明

**标题栏** —— 一行，安静，点整行折叠/展开。

- 左：状态圆点 + `楼层可见`；圆点只回答一个问题——最后一条对话楼层现在对 AI 可见吗（绿=可见，琥珀=已隐藏）。
- 中：`2/12 隐藏` 是隐藏数 / 总数；`⏱ 定时 2` 表示还有 2 条定时规则待执行，都是弱文字，不抢注意力。
- 右：`−` / `+` 折叠按钮；折叠后展开区整块收起，标题栏与 ai-monitor 的标题栏等高。

**展开区** —— Tab 与按钮固定，只有楼层列表滚动。

- 三个 Tab `全部 / 用户 / AI` 与 ai-monitor 的 `实时 / 历史` 完全同款（下划线标记当前项）。
- 三个批量按钮一行；`清除定时` 在没有规则时禁用。
- `最近 [N] 轮可见` + `应用` 一行：只保留最近 N 轮，边界保留对应的用户提问。
- 底部一行说明固定，滚动列表时不会顶掉。
- 展开区高度上限 `min(46vh, 360px)`（手机端 `min(52vh, 340px)`），超出时列表内部滚动，聊天区不会被无限顶上去。

```
⌄  #11  AI                                        (开)
⌄  #10  AI                                        (开)
⌄  #8   AI   [1 轮后可见]                          (开)
⌃  #6   AI   [3 轮后隐藏]                          (开)
   在 [3] 轮后 (到点开关) 隐藏                      ✓  ✕
```

- 列表**最新在前**，`#id` 是真实楼层号；点某一层会在它下面展开手风琴面板，再点一次收起，同时只开一个。
- 行里只显示 `#楼层号` + 角色，**不显示摘要正文**：正文留在聊天区看，列表只用来定位楼层；摘要退到悬停提示，鼠标停在该行上仍能确认是不是这一层。
- 每行右侧的开关直接控制该层对 AI 的可见性（与酒馆的隐藏状态一致）；隐藏楼层的 `#号` 划线并变灰。
- 有定时规则的楼层在开关左侧多一枚徽标（`⏱ 3 轮后隐藏`），没有规则时这一行只有楼层号、角色和开关。
- 展开内容不套卡片：**没有底色、没有描边**，左侧退回 chevron 之后，与楼层号对齐，看起来就是这一行的延续。
- 手风琴里的定时编辑是**一行**：`在 [N] 轮后` + 到点开关（隐藏 / 可见）+ 操作按钮。
- `✓` / `✕` **默认不出现**，只有在轮数或到点开关被改过之后才出现；改回原值又会消失。
- 已有规则的楼层额外显示删除按钮（垃圾桶），随时可以取消规则。
- `Esc` 先收起手风琴，再按一次折叠卡片。

## 定时规则怎么算「一轮」

- **一轮 = 一次 AI 回复**（`tavern_events.MESSAGE_RECEIVED`）。
- 规则从**设置那一刻**开始倒数：设「3 轮后隐藏」，接下来 3 次 AI 回复之后才执行。
- 撤回/重新生成也算一轮；`quiet` 静默生成不写进聊天，不算轮。
- 楼层被删除时，对应规则自动失效。
- 规则存在**聊天变量** `tt_message_visibility` 里，跟着聊天走，切换聊天互不影响。

## 已知限制

- 批量操作（全部隐藏 / 可见窗口）不会清掉已设的定时规则；两者冲突时以最后执行的为准。
- 「只让最近 N 轮可见」把第 N 轮之前的楼层（含开场白）一起隐藏；需要开场白时用 `全部可见` 或手动打开该层。
- 定时规则按本地轮次倒数，不跟随酒馆的「回退到某楼层」回溯。
- 筛选只影响列表显示，不影响 `全部可见` / `全部隐藏` / 可见窗口的作用范围（始终是全部楼层）。
- 筛选与「收起为状态条」是个人界面偏好，存在 `localStorage`（`tt-message-visibility:ui`），不随聊天切换。
